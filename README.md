\# Heart Disease Prediction



A machine learning project that predicts the possibility of heart disease based on patient health-related input features.



\## Project Overview



This project uses a machine learning model to analyze patient health-related data and predict the possibility of heart disease.



\## Technologies Used



\- Python

\- Scikit-learn

\- Joblib

\- Machine Learning



\## Project Files



\- `heartdp.py` - Python program for heart disease prediction

\- `hdp1.joblib` - Trained machine learning model

\- `requirements.txt` - Required Python libraries
